# Sample notes

The pages you see in the screenshots, ready to try.

1. Download this repo (green **Code** button › **Download ZIP**) and unzip it.
2. In PilcrowMD, open the sidebar, pick **Browse**, click **+** and choose the `Work Notes` folder.
3. Open any note. To see live updates, change or add a `.md` file in that folder with any other app.

| Folder | Notes |
|---|---|
| Engineering | readme.md, runbook.md, alert-flow.md (a Mermaid diagram) |
| Business | q3-review.md, spec.md, agreement.md |
| Research | lab-note.md, lecture.md |
| Writing | chapter-3.md, ai-answer.md |
